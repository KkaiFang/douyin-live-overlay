# 抖音直播间礼物墙

![Node](https://img.shields.io/badge/node-%3E%3D18-brightgreen)
![License](https://img.shields.io/badge/license-ISC-blue)

输入直播间地址，实时把每一位观众送出的礼物（头像、昵称、礼物、数量）做成 **3D 打印奖牌**：3D 打印机逐层把奖牌打印出来，揭幕后传送带运走。打印画面和队列信息页都可以直接作为 OBS 浏览器源使用。

采集器默认**不下载直播视频**，只保留事件 WebSocket，省流量。

**特性**

- 🖨️ **3D 打印奖牌**：Three.js 实时渲染的打印机 / 传送带现场，奖牌按礼物价值分档、逐层打印，揭幕后由机械臂取件送走
- 🖼️ **接单画纸**：另一套竖屏画面，把观众头像逐笔「画」成铅笔素描，盖上评分印章
- 📊 **OBS 即用**：`/studio`（3D 现场）、`/stats`（规则 + 实时队列）、`/sketch`（画纸）都是独立浏览器源，支持横屏 / 竖屏锁定
- 🔊 **语音播报**：浏览器原生 TTS 念进场欢迎、送礼答谢，无中文语音时自动回退服务端合成
- 🪶 **省流量**：只保留事件 WebSocket，拦截全部视频分片请求
- 🎁 **互动玩法**：关注 / 分享 / 点赞连击 / 每 5 分钟抽奖 / 评论区 666 彩蛋都会触发打印

## 快速开始

```bash
npm install
npx playwright install chromium   # 首次

npm run login     # 一次性：扫码登录（不登录收不到礼物消息）
npm start         # 启动服务
```

打开 **http://localhost:8181/** ，输入直播间地址，点「开始监控」。
点「我的 3D 工作室」是打印现场；「打开队列信息页」是规则和实时队列。

### OBS 里用

添加「浏览器源」：

| 项 | 值 |
|---|---|
| URL | `http://localhost:8181/studio`（3D 工作室）<br>`http://localhost:8181/stats`（打印规则 + 队列信息） |
| 宽 / 高 | 横屏 1920 × 1080；手机竖屏 1080 × 1920 |
| 关闭源时关闭页面 | ✅ |

`/studio` 右下角可以手动锁横屏（16:9）或竖屏（9:16），锁定后两侧补黑边，OBS 里不用再纠结窗口比例。

### 语音播报（进场欢迎 / 送礼答谢）

用 **浏览器自带的语音合成**（Web Speech API）实时念每个新进来的人的名字，送礼时再念一句答谢 + 随机吉利话。
手机、平板、电脑都能直接出声，不用装任何东西、不依赖服务端系统：

> 欢迎小鹿乱撞走进直播间，恭喜发财，钱包鼓鼓
>
> 感谢阿May的嘉年华，老板大气，福气加倍

- 会自动挑浏览器里的中文语音（优先 `zh-CN` 女声），没有就用系统默认中文
- 文案池在 `public/voice.js`（服务端 `lib/voice.js` 里有一份相同的，供兜底用），每句随机抽，不会一直重复同一句
- 同一人进场有冷却（控制台可调，默认 25 秒），小礼物 30 秒内同人同礼只说一次，大礼（≥100 抖币或连送 ≥9 个）单独念夸张版
- **兜底**：如果浏览器里一个中文语音都没有（比如 OBS 内置 Chromium、部分精简版系统浏览器），页面会自动改走服务端 `/tts`（macOS `say` 合成，缓存在 `.voice/`），连 OBS 也能出声

控制台「语音播报」卡片可以开关进场/送礼、调冷却和音量、点「试听」。设置通过 `POST /api/voice` 保存，并实时广播给所有已打开的展示页。

| 环境变量 | 默认 | 说明 |
|---|---|---|
| `VOICE` | 关 | `VOICE=1 npm start` 启动即开启语音 |
| `TTS_VOICE` | `Tingting` | 只影响服务端兜底音色，`say -v '?' \| grep zh_CN` 可换（如 `Shelley`） |
| `TTS_RATE` | 195 | 服务端兜底语速（120-320） |

> **注意自动播放**：手机 iOS/Android 和桌面浏览器都要求页面先被用户点过一次才能出声。打开 3D 工作室后点一下页面即可（OBS 里可以用「与场景交互」点一下）。
>
> 浏览器语音的音色由设备决定：iPhone/iPad 在「设置 → 辅助功能 → 朗读内容 → 声音」里可以下载更好听的中文女声（如「婷婷 · 增强」），下好后面板里会自动优先用它。

### 3D 工作室（`/studio`）

Three.js + WebGL 做的真 3D 场景，参考了同类开源项目的做法但代码是重写的：

- **场景**：木作工作台 + 窗帘 + 后墙书架 + 绿植 + 一扇透光的窗，暗调打光（顶光 + 冷暖轮廓光 + 暖色光晕），背景压暗可直接当直播画面
- **打印机**：黑铝型材 FDM，四根立柱、可升降龙门架、横向移动的喷头、顶上的料盘、玻璃打印床；喷头带火花粒子、风扇转、料盘在打印时慢慢出料
- **视角**：全景 ↔ 特写两档。**所有礼物和关注：打印全程保持全景，等奖牌被机械臂放上传送带后才沿全景视角原方向推进特写**（不换角度，镜头跟着奖杯随传送带移动，停约 3.7 秒自动回全景；关注奖牌揭幕时还会弹一下放大）；点赞 / 抽奖保持全景；右下角控制条（鼠标动一下或按 `H` 出现 3 秒）可手动切换，快捷键 `1` 全景 / `2` 特写
- **横竖屏**：控制条上「自动 / 横屏 / 竖屏」可锁定画面比例，锁定后按 16:9 或 9:16 渲染，两侧补黑边（OBS 里不用再纠结窗口比例），选择会记住；也可用 `?orient=portrait` / `?orient=landscape` 直接指定
- **打印头**：参考原版做法——倒角前面板、护网风扇、黄铜热端 + 倒锥喷嘴、四个进料嘴，料管从料盘一路牵到喷头，喷头移动时实时重算曲线
- **打印件**：相框勋章 —— 两个标签上下叠：**托座正面的浅色斜切石板写"打印原因"**（礼物名如「嘉年华」、`关注了主播`、`点赞连击`、`分享了直播间`、`抽奖中奖`），**基座正面的深色 LED 铭牌写观众昵称**；再往上才是金属边框、圆形头像和覆盖玻璃。用 **裁剪面逐层长出来**，打印完揭幕时喷头自动退到一边、玻璃反光扫过，打印完由取件机械臂抓起、摆正、放上传送带随皮带滚走
- **大小按礼物价值**：小礼 0.85 倍、中礼 1.0 倍、大礼 1.12 倍、超大礼 1.45 倍；点赞/关注/分享/666 固定 0.75 倍、彼此一样大；抽奖（幸运观众）0.9 倍，不抢礼物镜头
- **传送带**：皮带一直滚动，机械臂放上去的奖杯跟着一起往右滚，走到尽头滑出画面自动释放；奖杯都跟传送带平行摆放
- **分档**：按抖币总价值分 4 档（木头/青铜/银/金）；**所有礼物奖杯都戴皇冠，皇冠大小随档位变化**，超大礼另有金边；互动奖牌不戴皇冠
- **点赞连击**：攒够一波（默认每 20 下）打印一张小头像奖牌 + 语音答谢，优先级最低不跟礼物抢
- **关注 / 分享**：打印奖牌 + 语音答谢（「感谢某某关注了主播」）
- **进场打印**：在线 ≤50 人时，新进直播间的观众也打印一枚小奖牌（同一人 60 秒冷却）；在线超过 50 或人数未知不打印，优先级最低，礼物永远优先
- **抽奖**：每 5 分钟从最近观众里抽 1 人，理由写「幸运观众」；只抽最近 3 分钟内还在直播间有动静的（`?presence=180` 可调），没人就跳过这一轮，不硬抽
- **隐藏彩蛋**：评论区扣 `666`（连续 3 个以上 6）打印一张小奖牌，5 秒全局冷却防刷屏
- **测试口令**：评论「测试大号」打印一个大号奖牌，并自动推近特写，调试用
- **首次加载**：有加载遮罩，遮罩后面先把材质编译好，进入时不再卡一下；阴影只在画面动的时候重算；像素比自适应（掉帧降到 1、有余量再升回 1.5），1080p 下实测稳定 60 帧
- **性能**：像素比自适应（连续掉帧自动降），打印完的作品离开画面就释放显存，OBS 里 1080p 稳 60 帧
- **打印音效**：每次打印自动响起、揭幕渐弱。`public/printer.mp3` 是针式打印机录音（Daniel Simion @ SoundBible，CC BY 3.0）循环播放；删掉它则退回合成音（步进啸叫 + 风扇 + 走位吱声）。`?sfx=0` 关闭
- **语音**：`/voice.js`（浏览器原生语音合成），进场欢迎 + 送礼答谢 + 点赞答谢 + 抽奖播报

| 参数 | 默认 | 说明 |
|---|---|---|
| `?demo=1` | — | 合成礼物/关注/点赞/抽奖，单独预览动画 |
| `?alpha=1` | — | 透明背景，叠直播画面用 |
| `?edit=1` | — | 打开鼠标轨道相机，自己调构图 |
| `?hud=0` | 开 | 关掉左下角当前打印信息条 |
| `?printSec=4` | 4 | 单个作品打印时长（秒），比初版快一倍 |
| `?like=20` | 20 | 每多少点赞触发一次小头像打印 |
| `?orient=portrait` | 自动 | 固定竖屏 9:16（`landscape` 固定横屏） |
| `?ui=0` | — | 隐藏右下角相机控制条 |
| `?speed=1` | 1 | 整体节奏倍速 |
| `?lottery=0` | 开 | 关闭抽奖 |
| `?lotteryMin=5` | 5 | 抽奖间隔（分钟） |
| `?presence=180` | 180 | 抽奖池只保留最近多少秒内有动静的观众（近似"还在直播间"） |
| `?sfx=0` | 开 | 关闭打印音效 |

> 需要 WebGL2。OBS 内置 Chromium 一般可用；显卡驱动太旧会提示开不了 3D（换台机器或给浏览器源开硬件加速）。竖屏窗口会自动切竖构图，也可以在相机控制条里手动锁定。

### 接单画纸（`/sketch`）

竖屏直播画面：暖木桌 + 一台手机（显示「接单画纸」界面、当前观众头像和「剩余 / 已画」）+ 一叠画好的纸，右下角一只手拿铅笔正在画。

- **画什么**：真人头像直接做黑白灰度处理，再沿亮度/边缘生成一笔一笔的铅笔线，按笔迹顺序用柔边笔刷逐步把灰度图“擦”出来（参考开源素描动画的做法），最后盖一枚红色「评分 XX」印章和昵称
- **画谁**：目前**所有互动的观众都画**（进场 / 礼物 / 关注 / 分享 / 点赞 / 弹幕），同一人 10 分钟内只画一次；礼物优先
- **节奏**：单张约 14 秒（淡入 0.7s + 作画 12s + 盖章 1s + 移走 0.6s）；作画按“轮廓 → 内部轻排线 → 明暗与暗部加重”分段推进，画完盖上印章叠到最上面那叠纸里
- **双手**：素材来自 Pexels《Hand of a Person Holding a Pencil and a Blank Notebook》(作者 Tima Miroshnichenko，Pexels Free License)；右手握笔并按笔尖对齐落笔点，前臂沿用原肤色继续延长并自然伸到画外；左手在纸后托住纸面，两只手均使用完整抠图
- **参数**：`?demo=1` 用随机观众预览；尺寸按 1080×1920 设计，自动等比缩放居中

### 两页拆分（/studio + /stats）

打印画面和队列信息分成两页：`/studio` 只放 3D 打印现场，`/stats` 放规则和队列，适合做沉浸式直播画面。

- **数据只有一份**：打印任务由 `/studio` 独占管理，每 0.7 秒把队列快照经服务端 WebSocket 转发给 `/stats`，两个页面不会各算各的、也不会重复打印
- **队列实时可滚动**：`/stats` 每秒重绘一次，队列长了可以鼠标滚 / 手指拖（OBS 里用「与场景交互」）；内容没变不重绘，滚动位置不会跳
- **不露内部数据**：给观众看的规则和队列只写「送什么礼物 → 小/中/大/超大号奖杯」，抖币数值只在你自己看的控制台里
- **礼物 → 奖杯档位**由打印机页面根据真实收到的礼物统计，自动填充到 `/stats` 的「礼物优先打印」面板
- **两个页面要同时开**：`/stats` 打开时如果没人推快照，会显示「等待打印机页面…」，并每 5 秒自动重连询问一次；`/studio` 关掉后会显示「3D 工作室页面已关闭，队列暂停同步」

OBS 里通常这样摆：`/studio` 铺满主画面，`/stats` 竖屏摆在侧边（1080×1920 或等比缩小），两个都是独立浏览器源即可。

### 信息页参数（`/stats`）

| 参数 | 默认 | 说明 |
|---|---|---|
| `?demo=1` | — | 合成队列数据看排版 |
| `?bg=0` | 开 | 去掉沉浸背景，变透明（叠在直播画面上用） |

触发规则：礼物按 `抖币 × 数量` 分档（同时决定奖牌大小）并优先打印；同一人 6 秒内连送同一礼物会合并数量；关注/分享、每 5 分钟抽奖会生成互动奖杯；**点赞连击不打印，只语音答谢**；评论不打印（隐藏彩蛋 666 除外）；在线 ≤50 时进直播间也打印小奖牌（礼物始终优先），人数多时只进抽奖池不打印。

### 手机竖屏 / 沉浸式

`/stats` 就是按竖屏设计的（1080×1920）；`/studio` 在竖屏窗口下会自动切竖构图，也可以在控制条里手动锁定。

- 3D 工作室画面 + 右下角相机控制条（规则和队列在 `/stats` 里看）
- 预览用 `?demo=1`，叠直播画面时用 `?bg=0` 变透明

如果采集工具给的是横屏窗口、但你要竖屏画面，请把浏览器源尺寸直接设成 `1080 × 1920`（或把窗口拉成竖向），页面会自动切到手机版。

### 省流量（不下载直播视频）

采集器默认在 Playwright 上下文里拦截 `media` 请求和 `.m3u8/.ts/.flv/.m4s/.mp4` 等视频分片，只保留页面脚本、接口和事件 WebSocket。

| 环境变量 | 默认 | 说明 |
|---|---|---|
| `BLOCK_MEDIA` | 开 | `BLOCK_MEDIA=0 npm start` 关闭拦截（回归/调试用） |
| `BLOCK_IMAGES` | 关 | `BLOCK_IMAGES=1` 额外拦截图片（头像/验证码域名会保留） |

`GET /api/status` 的 `diag` 里有 `mediaBlocked`（已拦截数）和 `mediaLeaked`（拦截后仍下载的媒体数，正常应为 0）。

## 架构

```
控制台 (/)
   │  POST /api/room { room }
   ▼
lib/server.js ──── 状态管理 + REST + WebSocket 广播
   │
   ▼
lib/grabber.js ─── Playwright 驱动 Chrome，截获抖音 im websocket 帧
   │                 - 支持 start() / switchRoom()，浏览器复用
   │                 - 登录态保存在 .profile/
   ▼
lib/proto.js + lib/douyin-events.js ─── protobuf 解码 + 归一化事件
   │
   ▼
信息页 (/stats) ─── 收 /studio 的队列快照，展示规则与排队
3D 工作室 (/studio) ── 礼物/互动入队 → 逐层打印 → 揭幕 → 传送带出片
```

### API

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/status` | 当前状态（房间、在线数、计数） |
| POST | `/api/room` | `{"room":"链接或房间号"}`，启动或切换直播间 |
| POST | `/api/stop` | 停止监控 |
| POST | `/api/voice` | `{"enabled":true,"enter":true,"gift":true,"enterCooldown":25,"volume":0.85}`，语音开关与音量 |
| GET | `/img?u=<url>` | 头像/礼物图代理（绕过图床防盗链） |
| GET | `/tts?text=<句子>` | 合成语音（浏览器没有中文语音时的兜底），支持 Range |
| WS | `/events` | 事件流 |

## 已知限制

- **省流量默认开启**：采集器不下载直播视频，只收事件。需要恢复视频时用 `BLOCK_MEDIA=0 npm start`。
- **礼物必须登录才收得到**。游客态只下发进场/弹幕/点赞。详见 `docs/gift-login-findings.md`
- **登录态会过期**，收不到礼物时重跑 `npm run login`
- **同一 `.profile` 只能被一个进程占用**。启动服务前如果残留了 Chrome 进程，采集会静默失败。清理：
  ```bash
  pgrep -f "user-data-dir=.*liveroom/.profile" | xargs kill -9
  rm -f .profile/SingletonLock
  ```
- **采集窗口不要最小化**，会被浏览器限速
- **协议会变**，失效时改 `lib/douyin-events.js`，用 `node scripts/dump.js <消息名>` 重新定位字段
- **风控**：一次只监控一个直播间
- **合规**：非官方采集方式，抖音官方明确禁止通过非「直播小玩法」应用获取直播间互动数据。自用可以，商业化有风险
